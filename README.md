# AI Invoice Processing Engine

Автоматизация обработки счетов поставщиков: AI извлекает данные из PDF, а бизнес-правила проверяют реквизиты, находят дубли и определяют, когда нужна ручная проверка. Проект помогает сократить ручной ввод и избежать повторных записей.

## [Открыть демоверсию](https://alexzaytsev-ai.github.io/AI-Invoice-Processing-Engine/)

**Сайт работает автономно на тестовых данных.** Он показывает четыре сценария обработки и результаты проверок. Реальные записи в базе не создаются.

**Реальный n8n workflow представлен в репозитории отдельно и пока не подключён к сайту.** В нём описаны AI-извлечение, работа с PostgreSQL и внешними сервисами; демоверсия эти интеграции не запускает.

Свой PDF можно выбрать в интерфейсе, но для его обработки нужен backend. В деморежиме файл остаётся в браузере и не получает выдуманный результат.

## Возможности проекта

- Извлечение номера и даты счёта, поставщика, ИНН, суммы, валюты и банковского счёта.
- Проверка обязательных данных, поставщика по ИНН и совпадения банковских реквизитов.
- Защита от дублей по паре **ИНН поставщика + номер счёта**.
- Обновление изменённого счёта с увеличением версии записи.
- Остановка сомнительных случаев для ручной проверки.

## Четыре демосценария

| Сценарий                           | Результат в демоверсии                                                         |
| ---------------------------------- | ------------------------------------------------------------------------------ |
| Корректный счёт                    | Проверки пройдены, создана тестовая запись версии 1.                           |
| Повторная загрузка                 | Новая запись не создана, обновлений нет, версия сохранена.                     |
| Изменённый счёт                    | Обновлена та же тестовая запись; показаны изменения суммы и НДС, версия 1 → 2. |
| Несовпадение банковских реквизитов | Требуется ручная проверка; запись не создана.                                  |

Каждый сценарий запускается независимо, с заранее подготовленным состоянием.
