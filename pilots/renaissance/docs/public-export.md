# Что изменено в публичных копиях

Исходные три файла пользователя сохранены без правок. Публичные копии подготовлены отдельно.

| Изменение | Причина |
| --- | --- |
| Удалены `credentials` у нод | После импорта выбрать собственные подключённые аккаунты |
| Telegram User ID и Chat ID заменены на `YOUR_...` | Не публиковать личные настройки доступа |
| ID и URL Google-таблицы заменены на `YOUR_GOOGLE_SHEETS_DOCUMENT_ID` | Настроить собственную таблицу |
| Реквизиты в отдельной Add Supplier заменены вымышленными | Не публиковать исходные банковские данные |
| Удалены workflow ID, version ID, webhook ID и instance metadata | Экспорты должны переноситься между стендами |
| Удалена ссылка на внешний error workflow | Этот workflow отсутствует в предоставленном пакете |
| `active = false`, пустой `pinData` | Импорт требует собственной настройки; данные выполнений не включены |
| Настройки workflow сведены к `executionOrder = v1` | Удалены настройки, привязанные к исходному экземпляру n8n |

SQL-запросы обработки счетов и решений, бизнес-условия, названия нод, формат callback и расписания сохранены. Add Supplier остаётся отдельно от основной цепочки. В Parse Approval изменены только два значения разрешённых ID: до настройки реальные нажатия не пройдут проверку.

В пакет добавлены README, инструкции, журнал результатов, схемы, минимальный SQL для новой демонстрационной базы и вымышленные PDF. В них нет токенов, реальных счетов, подписей, печатей или скриншотов личной переписки.
