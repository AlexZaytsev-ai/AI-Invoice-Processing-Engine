# Результаты проверки пилота

Ручной прогон выполнен **13–14 октября 2026 года** на рабочем стенде пользователя. Источник результатов — выполнения n8n, сообщения Telegram, строки Google Sheets и подтверждения пользователя в ходе совместной проверки. Нагрузочного тестирования и замера экономии времени не было.

Экспорты в репозитории обезличены после этого прогона. Новые PDF в `demo/` созданы отдельно; полный прогон этих PDF в подключённых Gmail, Telegram и Google Sheets не выполнялся. Ниже результаты исходного пилота, а не заявление о проверке каждой новой демонстрационной копии.

## Что исправили после проверки

В уведомлении Account Mismatch обе строки реквизитов брались из данных PDF. Для «Счёт из справочника» заменили источник на `{{ $json.bank_account }}` — результат PostgreSQL. Сравнение в IF уже использовало разные источники и останавливало обработку; ошибка была в отображении уведомления.

## Проверка публичного пакета

Проведена локальная проверка JSON, соединений между нодами, ссылок в выражениях и отсутствия исходных credentials, личного Telegram ID, адреса Google-таблицы, реквизитов поставщика и данных выполнений. JavaScript-ноды проверены на локальных входных примерах, включая отклонение чужого пользователя и неверного чата. Это не заменяет реальный тест второго Telegram-аккаунта.

SQL-схема составлена по экспортам и проверена на соответствие используемым полям. Живой PostgreSQL и n8n для импорта публичного пакета в этой среде не запускались; подключённые API здесь повторно не вызывались.
